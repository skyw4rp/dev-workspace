# Mission execution reports

This folder holds **one execution report per mission**, produced after a bounded autonomous run.

| Convention | Example |
|------------|---------|
| Filename | `M-XXX_EXECUTION_REPORT.md` |
| Pattern | One mission → one report → one gate review |
| Guide | [`../MISSION_EXECUTION_GUIDE.md`](../MISSION_EXECUTION_GUIDE.md) |
| Queue | [`../NEXT_ACTION_QUEUE.md`](../NEXT_ACTION_QUEUE.md) |

Reports are workspace governance artifacts. They do **not** grant Visual Polish route PASS and do **not** replace Quality Gate functional DoD.

Do not store screenshot binaries here — keep evidence under `workspace/screenshots/visual-polish/`.
